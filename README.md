# LCD 첫 칸에서 달리는 로봇

## 1. 제작 목적
LCD 16×2의 첫째 줄 첫 번째 칸에 달리는 로봇을 표시하여
아두이노가 동작 중임을 직관적으로 확인하도록 하였다.

## 2. 준비물
- Arduino UNO
- I2C LCD 16×2
- 점퍼선 4개
- USB 케이블

## 3. 연결 방법
| LCD | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

## 4. 스케치
아두이노 코드 파일을 이 저장소에 업로드할 예정이다.

## 5. 동작 원리
5×8 픽셀의 Custom Character 8개를 등록하고,
100ms 간격으로 순서대로 표시한다.
팔과 다리의 자세를 바꾸어 제자리에서 달리는 모습을 표현하였다.

화면 전체를 지우지 않고 첫 번째 칸만 갱신하여 깜빡임을 줄였다.
delay() 대신 millis()를 사용하여 다른 작업도 실행할 수 있도록 하였다.

## 6. 연결도 및 데모 사진
실제 연결 사진과 LCD 동작 사진을 추가할 예정이다.

## 7. 설명 및 고찰
작은 픽셀 공간에서도 팔과 다리의 변화를 통해 움직임을 표현하도록 설계하였다.
이 애니메이션은 프로그램의 반복문이 실행되고 있음을 보여준다.
다만 센서나 통신 기능까지 정상임을 보장하는 것은 아니다.

실제 실행 후 움직임의 자연스러움과 개선할 점을 추가로 기록할 예정이다.
